
# AI Infrastructure Operations Assistant

An AI-powered platform designed to monitor server health,
analyze infrastructure incidents, and provide intelligent
troubleshooting recommendations.

## Project Goals

- Monitor server CPU and memory usage.
- Detect infrastructure incidents.
- Analyze server logs.
- Retrieve relevant troubleshooting documentation using RAG.
- Build an AI agent for infrastructure assistance.
- Develop APIs and a web-based operations dashboard.

## Technology Stack

- Python
- Pandas
- FastAPI
- RAG and LLM APIs
- PostgreSQL
- React and Next.js
- Docker and GitHub Actions

## Project Status

Phase 1: Building the server monitoring and incident
analysis prototype.

## Disclaimer

This project initially uses simulated infrastructure data.
No real infrastructure actions are performed.
